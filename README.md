# forged-of-the-dragon-games
A games webpage featuring dragon-themed games and interactive experiences


## Deployment
Connected to Vercel for automatic production deployments from `main`.

## Android PWA trial

Open the preview in Android Chrome, then use the Install game button when available,
or Chrome's menu → Add to Home screen → Install. Launch the gold F icon and check
3D rendering, rotation, zoom, tabs and game controls. This is an online-only trial:
Babylon.js is loaded from a CDN; no offline support or native APK is included.
Preview authentication may affect installation; do not disable project protection
for this trial. Production is unchanged until this branch is reviewed and merged.
